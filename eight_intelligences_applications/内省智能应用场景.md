## 一、内省智能定义

### 核心定义
- **加德纳定义**：对自身情绪、动机、目标、价值观敏感的能力
- **关键能力**：
  1. **自我觉察**：觉察自身情绪、想法、动机
  2. **目标设定**：设定并追求个人目标
  3. **价值观澄清**：澄清个人价值观与信念
  4. **情绪管理**：管理自身情绪与冲动

### 与全球智慧传统对应
- **易经**："君子以自昭明德" = 自我觉察
- **道德经**："知人者智，自知者明" = 自知之明
- **佛教**："自洲自依"（Atta-dipa） = 自依止
- **儒家**："吾日三省吾身" = 自我反思
- **基督教**："攻克己身" = 自我管理
- **伊斯兰教**："Muhasabah"（自我清算）= 自我审查
- **犹太教**："Cheshbon HaNefesh"（灵魂核算）= 自我审查
